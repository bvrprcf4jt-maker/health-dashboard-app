Privacy Policy

This application accesses Oura data only after the user has explicitly authorized access through Oura's OAuth consent flow.

Oura data is used solely for the user's personal health dashboard, visualization and analysis. The data is stored locally under the user's control.

Oura data is not sold, rented, shared with advertisers, or disclosed to third parties for commercial purposes.

The application requests only the data categories needed for its personal health functions. Authorization can be revoked through Oura, and locally stored data can be deleted by the user at any time.

Oura data is not used to train, fine-tune or improve any artificial intelligence or machine-learning model.
